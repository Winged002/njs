# Syntal Family UI — v3.3.4

The v3.3.4 redesign makes Newsjacking Core visually consistent with the Syntal product family. The primary reference is Syntal SSO; BlackBook contributes the denser CRM-style treatment used for tables, forms, review screens, and operational workspaces.

## Visual hierarchy

- neutral application background
- white primary rail and white context navigation
- green-tinted selection rather than dark/futuristic navigation
- organization identity presented directly in the context navigation
- compact sticky top bar
- flat bordered panels with minimal shadow
- small, predictable radii and control heights
- dense data tables with restrained hover states

## Preserved behavior

- Syntal SSO organization switching
- persistent secondary-menu scroll position from v3.3.2
- Website Builder route-tree persistence
- Learning Workers, Experiments, Attribution, Products, Campaigns, Collections, and Distribution
