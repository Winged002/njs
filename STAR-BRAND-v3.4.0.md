# Syntal Blue Star Brand — v3.4.0

## Canonical mark

The release uses `static/brand/syntal-star.svg`, reproduced from the supplied icon:

- white fill
- `#007AFF` outline
- 6-unit stroke
- four-point geometric star

The mark is treated as the identity anchor rather than as decoration on every component.

## Visual system

- Primary: `#007AFF`
- Primary hover: `#0066D6`
- Soft blue: `#EAF4FF`
- Blue line: `#CCE4FF`
- Ink: `#17212B`
- Muted: `#687887`
- Surface: `#FFFFFF`
- Application background: `#F4F7FA`

The application remains light, compact and operational. Blue is concentrated on primary actions, selected navigation, focus rings, links, meaningful accents and the product mark.

## Brand placements

1. Main navigation rail product mark.
2. Context-navigation product header.
3. Syntal sign-in story panel.
4. Browser favicon and theme color.
5. Subtle sign-in watermark/ambient geometry.

The old `N` monogram is no longer used as the primary NJS identity.
