# Professional UI Redesign — v3.3.3

The v3.3.3 redesign moves Newsjacking Core away from decorative glassmorphism and toward the restrained operational style used by BlueBook.

## Visual system

- Neutral #F5F6F8 workspace background
- White application surfaces with visible #DDE1E7 borders
- Dark persistent primary navigation rail
- White contextual navigation with clear selected states
- 8–10px component radii
- Restrained shadows used only for menus/modals/sticky inspectors
- 16px readable base text on main content with compact labels and metadata
- 40–42px form controls and buttons
- Stronger contrast and predictable spacing

## UX principles

- Actionable content first
- Explanatory text reduced and visually secondary
- Dense desktop layouts without tiny typography
- Consistent action placement
- Bounded panels rather than decorative floating layers
- Persistent navigation and preserved scroll position
