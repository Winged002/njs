# Glass Compact Redesign — v3.3.1

This release introduces a product-wide visual refresh focused on a more premium, bonita feel while keeping the application dense and efficient for daily work.

## Design goals

- More modern and premium visual identity
- Compact working density without feeling cramped
- Better hierarchy around navigation, actions, and review flows
- Cleaner continuity across Products, Workers, Analytics, Websites, and Experiments
- Preserve clarity for heavy operational use

## Main changes

- Glassmorphism-inspired primary rail and context navigation
- Sticky glass workspace bar
- Elevated compact cards and panels
- Compact data tables and input controls
- Refined quick-create menu and workspace switcher
- Ambient gradient background system for authenticated views
- Harmonized mobile treatment
